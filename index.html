Online Mode

Live servers · Discord-linked account · Banners progress chronologically

01

Join the Discord

Your game account is linked to Discord. Join the official server and verify.

discord.gg/blazingrebirth
02

Download the APK

From the official site or #downloads channel. If the download does not finish 100%, switch browser (Chrome to Firefox or vice versa) and try again.

blazingonline.wiki/download
03

Install

Open the APK. Play Protect will appear → tap More info / Show more → then Install anyway. Do not skip this step.

04

Sign in with Discord

Open the game → Sign in with Discord. Account is created automatically. Let it download the ~220 MB game data (Wi-Fi, keep screen on).

Link Discord later

Others → Account. DATA TRANSFER is not valid for Online — you must link from inside the game menu.

Banners

Starts with the 2016 One Tail Naruto banner. Banners change chronologically as the server progresses.

Separate accounts

Online and Offline are completely separate apps with separate accounts. Progress does not transfer between them.

02

Offline Mode

Launcher + game · Local save only · All banners available

Important: Offline data is saved only on your device. Deleting the game = permanent loss of progress. There are 2 separate offline modes with separate local accounts.

01

Download the correct APK

From the #downloads channel on Discord:
• ARM → real Android phone
• x86_x64 → emulator

02

Install the Launcher

Play Protect will appear → More info → Install anyway. Open the app (Naruto Sage Mode icon).

03

Update pop-up → Later

An update pop-up appears. Tap Later (it is an older version).

04

Switch to Beta channel

Open the left-side menu → Updates. Change first setting from Stable to Beta. Then press Check for updates.

05

Update to latest (v0.28+)

Press Update now. Wait until it reinstalls the app (white UI like first install) → press Install when prompted.

06

Fix + download game data

Reopen the launcher → press Fix. The game (original icon) will download. Play Protect may appear again (sometimes twice) → always More info → Install anyway until the Play button appears.

07

Play

When the Play button is visible, tap it to launch the game.

Vanilla mode

Starts at level 1 with 1000 pearls. All banners available from the start (unlike Online which starts in 2016 and progresses).

Rewards / Gameplay

You can change rewards and gameplay options from the Launcher → GAMEPLAY settings.

Local save only

Progress is stored on the device. Uninstalling the game deletes everything. No cloud backup.

03

iOS Sideloading

SideStore + LiveContainer · Unlimited apps · No PC required on iOS 27

Important: Use only official sources. The site sideinstaller.com is fake / malware. Official: sideinstaller.net and frizzlem.github.io/SideInstaller

Choose your path:
• iOS 27 → Method 1 — No PC (recommended)
• iOS 18–26 → first generate a pairing file on a PC (once), then continue with SideInstaller
• Or use Method 2 — With PC (iloader) for the full install from a computer

Method 1 — No PC (iOS 27)

Fully on-device on iOS 27. Keep LocalDevVPN connected the whole time. On iOS 18–26 this method needs a pairing file first — see how to generate it.

01

Install LocalDevVPN

Open App Store → search LocalDevVPN → install. Open the app and tap Connect. Keep the VPN on during the whole installation.

02

Install SideInstaller (official only)

Open Safari → go to frizzlem.github.io/SideInstaller. Install the DNS profile first, then pick a certificate and tap Install. Certificates get revoked often — try another if one fails.

Certificate that worked (as of Oct 2026):
China-Telecom-Corporation-Limited-XC-com-ctq-qmc-yiban-p
Expires ~2029 · long validity. If it is gone, pick any other available one on the page.

03

Install SideStore + LiveContainer

Open SideInstaller → make sure you see Tunnel connected (green) → sign in with an Apple ID (preferably a secondary / burner account) → select LiveContainer + SideStore → choose Nightly (recommended) → tap Install SS + LiveContainer. Wait until it finishes.

Pairing file:
• iOS 27: leave “Import pairing file” empty and install directly.
• iOS 18–26: you must import a pairing file first, then come back here to Install.

iOS 18–26? Generate pairing file first →

04

Trust + Developer Mode

1. Trust the certificate profile
Settings → General → VPN & Device Management. The profile may appear under a short company name (not the full long certificate name). Tap it → Trust → Trust again to confirm.

2. Trust the Apple ID (after SideStore installs)
Same place → find your Apple ID enterprise profile → Trust.

3. Developer Mode
Settings → Privacy & Security → Developer Mode → On (phone restarts).

4. Refresh
Open LiveContainer → open SideStore inside it → sign in with the same Apple ID → connect LocalDevVPN → manual Refresh.

05

Clean up

After everything works, go to Settings → General → VPN & Device Management and remove the SideInstaller DNS profile. Keep LocalDevVPN installed — you need it for weekly refreshes.

Generate pairing file (iOS 18–26 · once on PC)

← Back to Method 1 (No PC)

Required only on iOS 18–26 if you use SideInstaller without a full PC install. On iOS 27 skip this. You only need a computer once; after that everything is on-device with LocalDevVPN.

Download iDevicePair (official):
Windows (64-bit) · macOS · Linux x86_64
Docs: SideStore — Pairing File

01

Windows only — install iTunes

Install iTunes 64-bit from Apple (needed for USB drivers). Mac and Linux do not need this.

02

Connect iPhone + Trust

Unlock the phone → plug in via USB → tap Trust on the phone and enter your passcode. Keep the phone unlocked on the Home Screen.

03

Generate with iDevicePair

Open iDevicePair → select your device → Generate (use RPPairing / remote pairing if the option appears — for iOS 17.4+). Tap Trust again on the phone if asked. You get a .mobiledevicepairing file.

04

Transfer to iPhone + import

Send the file to the phone (AirDrop, email, USB Files). Open SideInstaller → Import pairing file → select it.

Pairing file imported? Continue installation:
→ Go to Install SideStore + LiveContainer
or back to Method 1 overview

Method 2 — With PC (iloader)

Works on most iOS versions. You only need the computer for the first install. After that everything is on-device.

01

Install LocalDevVPN + iloader

On iPhone: install LocalDevVPN from App Store and connect it. On computer: download iloader from the official SideStore docs or iloader.app.

02

Connect & install

Connect iPhone via USB → trust the computer. Open iloader → sign in with Apple ID → select your device → choose LiveContainer + SideStore (or SideStore first). Install.

03

Trust + Developer Mode + Refresh

Same as Method 1: Trust the profile, enable Developer Mode, open SideStore / LiveContainer, sign in, do a manual refresh with LocalDevVPN connected.

Install the game (.ipa)

After SideStore + LiveContainer are working, install Naruto Blazing Rebirth as an IPA. Prefer installing it inside LiveContainer so it does not use one of the 3 free app slots.

01

Get the IPA

Download the official .ipa from the Discord #downloads channel (or the link shared by helpers). Save it to the Files app (On My iPhone / iCloud Drive).

02

Install via LiveContainer (recommended)

Open LiveContainer → tap the + button → select the .ipa from Files. Wait for it to import. Then long-press the app card and choose Launch (or set it as the default launch app). This way the game runs inside LiveContainer and does not count toward the 3-app limit.

03

Alternative: install via SideStore

Open SideStore (from LiveContainer or standalone) → My Apps → + → choose the .ipa. When asked, select Keep App Extensions (Use Main Profile). Trust the app if prompted. Note: this uses one of the free slots.

04

Refresh when needed

Every ~7 days the signature expires. Connect LocalDevVPN → open SideStore → tap the 7 DAYS timer on LiveContainer (and on the game if it was installed outside). Then relaunch from LiveContainer.

Why LiveContainer?

Free Apple ID allows only 3 sideloaded apps. LiveContainer runs other apps inside itself so they don’t count toward the limit.

7-day refresh

Apps expire every 7 days on a free Apple ID. Connect LocalDevVPN and refresh inside SideStore (or use scheduled refresh if available).

Burner Apple ID

Strongly recommended. If Apple locks the account you don’t lose your main one.

Fixes & Troubleshooting

Most common issues and real solutions from helpers

Online — Communication / Connection error

During installation you must press More info / Show more → Install anyway. If you skipped this, uninstall and reinstall correctly.

Turn off antivirus, firewall and Private DNS temporarily. These often block the connection to the private server.

Some regions need a VPN. European servers are recommended. Connect to an EU location and try again.

Offline — Communication / Connection error

You must switch to Beta channel and update to the latest version (see Offline installation steps 4–5). Old launcher causes connection errors.

Same as Online: More info → Install anyway. If you continued without this, reinstall both launcher and game properly.

Delete the APK and redownload from #downloads. Incomplete downloads are common.

Force close the game completely and reopen, or restart the phone. Simple but often works.

Disable antivirus and Private DNS. Same issue as Online.

Some regions need a European VPN even for Offline mode.

iOS — Common problems

Go back to the official install page and try another available certificate. Certificates get revoked frequently.

Settings → General → VPN & Device Management → tap the developer profile → Trust.

Make sure LocalDevVPN is connected. Open SideStore → My Apps → tap the 7 DAYS timer to force a refresh.

Wait 15–30 minutes or use a different (older) Apple ID. Very new accounts are often restricted by Apple.

Important notes

Emulator, accounts and common mistakes

EMULATOR

Use Pie64 image

Many users from USA and Asia automatically get the Nougat image. Offline update then crashes. Always choose the Pie64 (Android 9 64-bit) system image when creating the emulator instance.

ACCOUNTS

Online ≠ Offline

They are completely separate applications with separate accounts. Progress never transfers. Online links via Discord (Others → Account). Offline is local only.

ONLINE

No Data Transfer

The old Data Transfer code does not work for Online. You must link the account from inside the game: Others → Account → Discord.

OFFLINE

Local data only

Everything is stored on the phone/emulator. Uninstalling the game or clearing data = permanent loss. There is no cloud backup.
